# FinTrack – Smart Expense & Budget Manager

FinTrack is a React-based personal finance management web application that helps users track income, expenses, budgets, and spending patterns.

## Features
- Dashboard with income, expenses and balance
- Add and delete transactions
- Transaction history
- Spending analytics
- Monthly budget tracking
- Responsive design for desktop and mobile
- Data persistence using LocalStorage

## Technologies Used
- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- LocalStorage

## Deployment
Live Website: https://fintrack-expense-manager-ten.vercel.app/

## Conclusion
FinTrack provides a simple and user-friendly way to manage personal finances and monitor spending efficiently.
